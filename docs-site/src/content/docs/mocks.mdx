The mock in `web/` is the credit-officer app with an in-browser mock API: a
map of rural properties around Canguçu (RS) with climate risk and compliance
colouring, a property panel, a portfolio dashboard, alerts and a printable
report. It is rebuilt from `main` with this site, so it always shows the
current design.

<LiveMock />

:::note
The real public data layers (CAR, indigenous lands, protected areas) come
from tiles built by the Python ingest and are not published here yet, so the
"Land tenure" legend says they are missing. The screenshots below show them.
:::
